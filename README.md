# Hotel Reservation System

## Overview

The Hotel Reservation System is a console-based Java application developed as part of the CodeAlpha Java Programming Internship.

This project allows users to:

* View hotel rooms
* Book rooms
* Cancel reservations
* Manage customer booking details
* Track room availability

The application is developed using Object-Oriented Programming concepts and demonstrates real-world hotel booking operations.

---

## Features

* Room management system
* Room categorization (Standard, Deluxe, Suite)
* Room booking and cancellation
* Payment simulation
* Reservation tracking
* Hotel statistics display

---

## Technologies Used

* Java
* OOP Concepts
* ArrayList
* LocalDate API
* Scanner Class
